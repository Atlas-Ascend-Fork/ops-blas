# Cgeam 测试

## 测试数据

| 文件 | 用例数量 | 用途 |
| --- | ---: | --- |
| `arch35/cgeam_test.csv` | 50 | 默认测试输入，按原始顺序保留全量文件的前 50 条用例。 |
| `arch35/cgeam_test_full.csv` | 1200 | 完整用例，包含 1000 条精度用例和 200 条性能场景输入。 |

`cgeam_test.cpp` 按同名规则读取 `cgeam_test.csv`，默认只执行其中的 50 条 CSV 用例，不会自动加载全量文件。原有的 18 条基础接口检查继续执行，默认共运行 68 条测试。

全量文件保留原有全部字段、数值和顺序。本次拆分不修改算子实现、参考计算或精度判断标准。

## 运行

加载本机 CANN 环境后，在仓库根目录执行：

```bash
bash build.sh --ops=cgeam --soc=ascend950 --run
```

默认测试结果仅代表上述 50 条 CSV 用例及基础接口检查，不代表全量精度或性能验证结果。
